# 队列匹配资料

cases和controls的id在本文件全局唯一，stratum为已锁定的离散精确匹配层。covariates包含scales全部同名列，null表示未观测，不能参与相应病例的候选边。所有测量值和scale都是有限十进制资料；需要精确费用时按JSON原十进制文本解析，不先转二进制浮点再声称有理精确。

cost_weights为非负有理数且至少一个正，caliper_sets每个维度上限非负；距离为绝对差除scale，费用为有符号标准化差的平方加权和。k是每病例所需不同对照数，capacity是该对照可被不同病例复用的正整数上限。outcome为合成二元结果。公开资料中x3有缺失，c2允许复用。

观察摘要只读协变量和容量，不生成候选边、匹配或估计效果。
